NetForensics — PCAP Forensic Analysis Platform

Southeast Missouri State University · Spring 2026

A full-stack forensic analysis tool that parses packet captures and surfaces traffic patterns, malware indicators, exfiltration attempts, credentials, port scans, and a full investigation timeline — built as our senior capstone project.

I owned the backend: all 7 Flask REST API endpoints, a PyShark PCAP parser, magic-byte server-side file validation, Flask-Login session management with Bcrypt password hashing, and fpdf2-based PDF/CSV report generation. I also designed all four UML models (Use Case, Class, Sequence, Activity), validated every endpoint against the React frontend, and wrote subprocess-level tests confirming our TShark integration matched Wireshark's ground truth on both Windows and Linux.

💡 Lesson learned: PyShark's eager-load mode blew past our 5-minute performance requirement on 1 GB files (7+ minutes). Switching to lazy iteration cut load time to 3m 42s — catch performance-sensitive architecture decisions during design, not during Week 4 testing.
